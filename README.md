# 🌍 Country Flags Encyclopedia

An interactive web application that allows users to explore countries through their national flags. Users can search for countries and discover useful information, including capital cities, population, and geographical regions, through a modern and responsive interface.

## ✨ Features

- Explore 30 countries and their national flags
- Search countries by name
- Interactive flag gallery
- Premium country details popup
- View capital cities
- Display population information
- Explore geographical regions
- Smooth popup animations
- Click outside or press Escape to close the popup
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vibinsonraj05/Country-Flags-Encyclopedia.git
```

### 2. Navigate to the project directory

```bash
cd Country-Flags-Encyclopedia
```

### 3. Run the application

Open `index.html` in your web browser.

**Note:** Keep the `assets` folder in the same directory as the HTML file to ensure all country flag images load correctly.

## 🎯 How to Use

1. Open the application in your browser.
2. Browse the available country flags.
3. Search for a country using the search bar.
4. Click on a country card to view its details.
5. Explore its capital, population, and region.
6. Close the popup using the close button or Escape key.
